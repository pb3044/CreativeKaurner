# CreativeKaurner

Handmade coastal studio on **Vancouver Island, BC** — painted beach finds, knit bags, custom art, keepsake cards, and coastal prints. Gifts for Christmas, Thanksgiving, weddings, birthdays, and more.

Live site: [creativekaurner.ca](https://creativekaurner.ca) (static HTML on GitHub Pages).

## SEO & discovery

- Per-page title, description, canonical, Open Graph, and Twitter cards
- JSON-LD `LocalBusiness` on the home page (includes Instagram `sameAs`)
- [`robots.txt`](robots.txt) and [`sitemap.xml`](sitemap.xml)
- Favicon set: `favicon.ico`, `images/apple-touch-icon.png`, `images/icon-32.png`, `images/icon-192.png`, `images/icon-512.png`, [`site.webmanifest`](site.webmanifest)

After deploy: submit the sitemap in [Google Search Console](https://search.google.com/search-console) and [Bing Webmaster Tools](https://www.bing.com/webmasters).
